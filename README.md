# Треноги

**Треноги** — это игра от первого лица про выживание во время вторжения инопланетян. В первый день над городом гаснет свет, бьют 25 молний, а из-под земли поднимается первый боевой треножник. Дальше выбирать тебе: прятаться в доме, идти на фронт или искать свой путь.

> ⚠️ **Игра работает только на Windows 10 и Windows 11 (64-бит).** На Windows 7, 8, 8.1, 32-битной Windows, macOS и Linux она не запустится. Если у вас другая система, которая официально поддерживает программы для Windows 10 x64 (например Windows Server 2019/2022), игра, скорее всего, тоже пойдёт.

🌐 **Языки:** русский и английский.

## ⬇️ Скачать

Установщик **Setup_Trenogi.exe** лежит в разделе **[Releases](../../releases/latest)**.

1. Скачайте `Setup_Trenogi.exe`.
2. Запустите его. Windows может показать синее окно «Windows защитила ваш компьютер», потому что у установщика нет платной цифровой подписи. Нажмите **«Подробнее» → «Выполнить в любом случае»**.
3. Выберите язык: **русский** или **английский**. На этом языке будут и установщик, и игра. Позже язык можно поменять в меню игры.
4. Выберите папку и отметьте нужные ярлыки (рабочий стол / меню «Пуск»), затем нажмите «Установить».
5. Играйте!

## 🖥️ Системные требования

|                | Минимальные                              | Рекомендуемые                          |
|----------------|------------------------------------------|----------------------------------------|
| **ОС**         | Windows 10 64-бит (версия 21H1 или новее) | Windows 11 64-бит                      |
| **Процессор**  | 4 ядра, ~3 ГГц (Intel Core i5-4460 / AMD Ryzen 3 1200) | 6+ ядер (Intel Core i5-10400 / AMD Ryzen 5 3600) |
| **Оперативная память** | 8 ГБ                             | 16 ГБ                                  |
| **Видеокарта** | DirectX 11, 2 ГБ видеопамяти (GeForce GTX 1050 / Radeon RX 560) | 6 ГБ видеопамяти (GeForce GTX 1660 Super / RTX 2060 / Radeon RX 5600 XT) |
| **DirectX**    | версия 11                                | версия 12                              |
| **Место на диске** | 300 МБ                                | 300 МБ (желательно SSD)                |

**На чём проверено:** GeForce RTX 3060, Intel Xeon E5-2667 v4 (8 ядер, 3,2 ГГц), 32 ГБ ОЗУ, Windows 11. Здесь игра идёт плавно на максимальной графике.

Графика в игре по умолчанию выкручена на максимум: тени высокого качества, сглаживание 8x MSAA, динамический свет. На слабых видеокартах (встроенная графика Intel HD/UHD, GT 710/730) будут сильные тормоза. Минимальные требования примерные: игра проверялась только на одном компьютере.

## 🎮 Что есть в игре

- Город, который разрушается с каждым днём вторжения.
- Семь видов треножников: Скаут, Купол, Прожектор, Гигант, Страж, Багровый и Древний.
- Ночные охотники с лазерами, щупальца-камеры и сети, в которые треножники собирают людей.
- Повестка в почтовом ящике. Если её подписать, утром за тобой приедет военный грузовик с другими призывниками и отвезёт на фронт. Там ждут окопы, пулемёт, ракетница, рация с авиаударами и танк. А можно выбросить её и выживать дома.
- С солдатами и призывниками можно поговорить (E).
- Ежедневник, еда, фонарик, оружие и верстак.
- **5 концовок:**
  1. Выжить в доме
  2. Победить на войне
  3. Стать суперучёным
  4. Стать мутантом
  5. Стать Праймом

<details>
<summary>Подсказки к секретным концовкам (спойлеры!)</summary>

- **Суперучёный:** где-то рядом есть пещера с кристаллами. Из них на верстаке можно собрать кое-что очень необычное…
- **Мутант:** на окраине города стоит атомная станция. Говорят, уран лучше не есть…
- **Прайм:** на лугу к востоку от дома стоит заброшенная мастерская. А за ней каменный холм, из которого светится что-то зелёное…

## ⌨️ Управление

| Клавиша | Действие |
|---|---|
| W A S D | Ходьба |
| Мышь | Обзор / стрельба |
| Shift | Бег |
| Пробел | Прыжок |
| Ctrl / C | Присесть |
| E | Взаимодействие |
| F | Фонарик |
| Q | Поесть |
| R | Перезарядка |
| 1–9, 0 / колесо мыши | Выбор оружия (слоты идут по порядку подбора) |
| ПКМ / G / V / H / T | Особые способности (открываются по ходу игры) |
| Esc | Пауза / меню |

## 🇬🇧 English

**Tripods** (Russian: *Треноги*) is a first-person alien-invasion survival game. On the first day the city goes dark, lightning strikes the same spot 25 times, and a giant war tripod rises from the ground. Hide at home, go to the front, or find your own way out. The game has **5 endings**.

- **Windows 10 / 11, 64-bit only.** It won't run on Windows 7/8/8.1, 32-bit Windows, macOS or Linux.
- **Languages:** English and Russian. You pick the language when you run the installer, and you can change it later in the game menu.
- **Download:** `Setup_Trenogi.exe` from **[Releases](../../releases/latest)**. If SmartScreen says "Windows protected your PC", click **More info → Run anyway**. The installer isn't code-signed.
- **Minimum:** 4-core ~3 GHz CPU, 8 GB RAM, DirectX 11 GPU with 2 GB VRAM (GTX 1050 / RX 560), 300 MB disk.
- **Recommended:** 6+ core CPU, 16 GB RAM, GTX 1660 Super / RTX 2060 / RX 5600 XT, SSD.
